# Final Çalışma Sitesi

## GitHub Pages'e Yükleme (3 adım)

### 1. Repo oluştur
github.com → sağ üst + → **New repository** → isim ver → Create

### 2. Dosyaları yükle
**ÖNEMLİ:** ZIP içindeki `sinav-sitesi` klasörünün **içindekileri** yükle, klasörün kendisini değil.

Yani repo'nun kök dizininde şu yapı olmalı:
```
index.html          ← direkt burada
pdfs/               ← bu klasör direkt burada
  fizyoloji_...pdf
  anatomi_...pdf
  farmakoloji_...pdf
  patoloji_...pdf
README.md
```

### 3. Pages'i aç
Repo → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → **Save**

2-3 dakika sonra: `https://KULLANICIADINIZ.github.io/REPOADI`
